# Keylogger V1

## Install
To use, download both the python and json file and make sure they're in the same directory.

## Config
By default, the keylogger deletes the contents of the **logged.json** file every time it is run - if you don't want this to happen, go to **keylogger.py** and set the <span style="color:red;">**DELETE_PREV_CODE**</span> variable to **False**.
